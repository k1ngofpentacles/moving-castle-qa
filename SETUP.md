# Pack setup

Minecraft **1.21.1**, NeoForge **21.1.265**. Install every mod below (Prism Launcher: Edit instance > Mods > Download mods, or the links). Install all of them on every computer, including the LAN host. Voxy (a distant-terrain renderer) is in the developer's copy but cannot be redistributed: leave it out.
